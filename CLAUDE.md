# Beacon Remote contributor entry point

Read [docs/workspace.md](docs/workspace.md), [docs/roadmap.md](docs/roadmap.md), [docs/architecture.md](docs/architecture.md) and [docs/security.md](docs/security.md). The workspace guide is the shared entry point for every coding agent; there is no separate model-specific handoff.

Use the current approved feature branch and check Git status before changing files. Source publication, CI and compilation do not establish device, boot, privacy or network acceptance. Follow docs/deployment.md for a separately authorized rollout; never infer production state from a historical document.

Preserve visible capture, consent, revocation, single-controller leases, short grant expiry, Windows UAC/UIPI/Session 0 boundaries and independent View/Motive identities. Do not stop unknown listeners or add paid infrastructure as housekeeping. The approved static visual reference is in design/prototype; it is not a working security implementation.
