# Approved Beacon Remote visual reference

Open index.html for the surrounding product flows and workspace/index.html for the approved application layout. The HTML/CSS/JavaScript uses simulated data. It defines visual targets, not functioning authentication, signing, security or remote access. Consult ../../docs/roadmap.md before implementing a screen or claiming a feature works.

DESIGN_SPEC.md contains the supplied visual specification. Canonical preview images are already in ../screenshots/reference/approved-mockup; duplicate previews, one-off QA scripts, old results and executable agent prompts were removed during organization.

Keep this reference separate from apps/web: do not deploy its sample accounts, success states or static downloads as the product.
