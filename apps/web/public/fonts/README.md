# Bundled fonts

Self-hosted from Fontsource (jsDelivr). Both families are licensed under the SIL Open Font License 1.1.

| File                             | Family                     | Use                                    |
| -------------------------------- | -------------------------- | -------------------------------------- |
| `atkinson-next-var.woff2`        | Atkinson Hyperlegible Next | All interface and page text (variable) |
| `atkinson-next-var-italic.woff2` | Atkinson Hyperlegible Next | Italic (variable)                      |
| `atkinson-mono-var.woff2`        | Atkinson Hyperlegible Mono | Pairing codes, device IDs, hashes      |

Atkinson Hyperlegible was designed by the Braille Institute for character recognition. Latin subset only.
