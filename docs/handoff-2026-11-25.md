## Hard-won lessons

- **Media path:** the browser can nominate the Wi-Fi or Tailscale route (30-40 ms, throttled) and the video never
  decodes. Blocking _outbound_ UDP made the helper stop with "Media consumer stalled" (a blocked send fails inside the
  media stack). The working fix is the _inbound_ drop.
- **Input safety:** the owner follows this conversation from a window on Surfiena. Keystrokes sent there while that window
  was in front were delivered as user messages twice ("7*6", "echo ok"). Always `lab.mjs raise` a window you own and
  confirm `lab.mjs foreground`; the helper now requires `--window` for keys and text. Through the viewer use key
  presses (`key e c h o ...`); text insertion is not forwarded. Never type into the owner's windows.
- **Stale viewer state:** the web app resumes the last view; a leftover "Session ended" view swallows the next Connect.
  Close it (or reload and close) before connecting.
- **Elevation:** whether a UAC prompt appears is unclear; some elevated runs started without one. Results of each
  elevated step are written to a file in `BeaconLab`; read it rather than assuming.
- Windows Notepad reuses the open window; launching it can add a tab to the owner's document. Use a console you create.
- The agent never prints or logs typed text; do not add it.
